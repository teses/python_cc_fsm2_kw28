# Was ist Pandas?

- Pandas ist eine Python-Bibliothek zur Verarbeitung und Analyse von Daten.
- Besonders geeignet für tabellarische Daten, z. B. aus CSV-, Excel- oder Datenbankdateien.
- Pandas basiert teilweise auf NumPy und erweitert dessen Möglichkeiten um komfortable Datenstrukturen und Funktionen.
- Die wichtigste Datenstruktur ist das DataFrame – vergleichbar mit einer Tabelle in Excel oder einer SQL-Tabelle.

# Was kann Pandas?

| Aufgabe          | Beispiel                              |
|------------------| ------------------------------------- |
| Daten einlesen   | CSV, Excel, JSON, SQL                 |
| Daten untersuchen | Spalten, Datentypen, fehlende Werte   |
| Daten bereinigen | Duplikate und `NaN` entfernen         |
| Daten verändern  | Spalten hinzufügen, Werte ersetzen    |
| Daten filtern    | z. B. alle Produkte mit Preis > 100 € |
| Daten analysieren | Mittelwert, Summe, Minimum, Maximum   |
| Daten gruppieren | `groupby()`                           |
| Daten verbinden  | `merge()`, ähnlich wie SQL `JOIN`     |
| Daten sortieren  | nach einer oder mehreren Spalten      |
| Daten exportieren | CSV, Excel, JSON usw.                 |
