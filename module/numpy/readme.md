
# Was ist NumPy?

- NumPy (Numerical Python) ist eine Bibliothek für effiziente Berechnungen mit großen, mehrdimensionalen Arrays und Matrizen.
- Bietet viele mathematische Funktionen, die auf Arrays arbeiten (ähnlich wie in MATLAB).
- Arbeitet intern mit C-Code, daher ist NumPy schneller als reine Python-Listen.
